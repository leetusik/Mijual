The repl's globals include node-ish **`fs` and `pwd`, scoped to that invocation's own session directory**, so a probe file in the repo cannot be read from the script: inline it as a JSON literal and pass the whole script from a shell **variable** (`CODE=$(cat f); aside repl --account u2 "$CODE"`) — a literal `"$(cat f)"` lets the shell eat its backslashes.

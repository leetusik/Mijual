# Plan — P13.S1 (implementation, `slice-executor-high`)

**Backend for the signup email-verification gate.** After this slice, `POST /auth/signup` creates an unverified account, mails a single-use 6-digit code and opens no session; `POST /auth/verify` (password first, then code) verifies the account and logs the reader in; `POST /auth/login` with the correct password on an unverified account opens no session and answers `verification_required`; `POST /auth/verify/resend` supersedes the live code under a cooldown; a completed password reset also verifies; every account that exists today is verified by the shape of the new column. Backend only — no frontend file is touched (that is S2).

**Read first:** `works/phases/active/P13/phase.md` — `## Decisions` fixes the schema, the grant, the **whole API contract** (endpoint names, request/response shapes, structural codes, the numbers: 10-minute lifetime, 5 attempts, 60-second cooldown), the three-kind mail rule and the copy route; `## Notes for later slices` carries four notes tagged `for P13.S1` — consume them. `intent.md` only if something is unclear. Build **exactly** the contract in `## Decisions`; if you must change an endpoint name, a response shape or a code, replace that line in `## Decisions` (S2 builds from the notebook, not from your prose) and say why in `result.md`.

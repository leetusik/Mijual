# Phase P13: Email verification at signup (6-digit code)

_Intent: see [intent.md](intent.md)._

## Objective

Registration requires proving control of the address: signup creates the account unverified, mails a single-use 6-digit code and opens no session; the auth panel switches to a code-entry state on the same surface, and the right code verifies the account and logs the reader in. Logging in with the correct password on an unverified account routes to the same code step with a 재전송 option. Existing production accounts are grandfathered as verified by the migration. No design round: the phase extends the signed R5/R12 auth vocabulary and the operator approves the exact Korean strings at the acceptance gate. The verification mail is proven live on production.

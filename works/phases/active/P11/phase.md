# Phase P11: Ask agent polish: inline citations and feature cards

_Intent: see [intent.md](intent.md)._

## Objective

Fix two operator-reported defects on the AI 질문 surface. (1) Citation chips break the prose: InlineCitation's always-mounted .quoteWrap is display:grid — a block box in <p class=prose>'s inline flow — so every chip forces a line break and a sentence resting on two or more 근거 renders as 「…입니다.[1] ⏎ [2] ⏎ [3]」. Re-cut the ask chip onto the conditionally-mounted absolute-popover anatomy components/Citation.tsx already ships (R10), so chips follow the sentence's period inline and adjacent chips sit side by side — across all three signed placements (프로즈 · 데이터 행 값 · 계산 입력), on the page and the widget, at desktop and ≤767. Server-side numbering is correct and is not touched. (2) The four hard-coded START_CHIPS_KO cards are all read-a-filing questions, exercising only search_events/get_event and leaving calculate, get_portfolio, save_feedback and get_contact invisible. Replace them with a card set — count freed from D11's 'exactly four' by operator instruction — chosen so that clicking the cards one at a time demonstrates every agent capability, keeping R16's layout and the 'card sentence is the question sent' rule. Lands before P4 so the demo video shows both.

## Decisions

_Durable cross-slice decisions. Replace a superseded line; never stack versions._

- **The cards stay hard-coded Korean strings in `components/ask/copy.ts`** (Q1). A served/derived set
  costs an endpoint, a loading state and a fallback on the one screen that must never look empty, for
  nothing the reader sees. Aging is handled in the copy: P11.S2 picked companies live in the corpus
  now (none expiring before 2026-09-07) and confirmed each card answers. A data-derived set is filed
  as a deferred-job candidate at P11.REVIEW.
- **Six cards, one capability each, and the six sentences shipped unchanged** (Q2 + the mapping):
  검색 `HLB 전환사채 공시가 몇 건이나 있나요?` · 이벤트 `접수번호 20260730000215 공시에는 무슨 내용이
  있나요?` · 계산 `에코프로비엠 유상증자, 1,000주 보유 시 배정 신주는 몇 주인가요?` · 포트폴리오 ·
  **의견** (a first-person opinion, so nothing is filed behind the reader's back — it writes a real
  queue row, which is the capability) · 연락처. `security_check` is not a card. **A bare 접수번호 is
  the only shape that isolates `get_event`** (a company+field question fires 검색 *then* 이벤트).
  All twelve presses (dev + production) hit the intended tool row on the **first** sentence written.
  R16 D11's set-level rules survive the count change; `D11` is R16's *design decision* id, and
  `intent.md`'s operator instruction supersedes its 「4장」 in the P7 override style.
- **Chip anatomy: one component, one anatomy (P11.S1).** Conditional mount + absolute popover in both
  placements (R6-4). Prose `.citationWrap` = `relative; inline-block`; the row keeps `display:
  contents` and the popover anchors to `.row`, which took `position: relative`, so R16 §2.6's 「행
  아래, 블록 전폭」 survives (732px at 1280 / 354px at 390) and the value-column collapse is
  structurally impossible. `.quoteWrap`/`.quoteClip`/`.quotePanel`/`.quoteOpen` and `inert` retired.
- **The popover's ground is opaque — the phase's one deliberate deviation from R16.** `--surface-inset`
  was signed for an *in-flow* panel; as an overlay it lets the sentence read through the evidence. The
  2px `--live` edge and the 180px cap stand; the fill is the product's own overlay ground (`#0e1a15` +
  1px `--border-strong` + `--panel-glow`). No new colour. **The operator is told this at the gate.**
- **Close model = 칩 재탭 (R6-4) + press outside + Esc-with-focus-return (R10 §6); no `×`.** `fit()`
  measures the nearest clipping box ∩ viewport and flips upward — the 620px widget thread clips.

## Decisions

_What is true now; superseded lines are replaced, not stacked. The reasoning behind each one is in
that slice's `result.md`, and the durable form is in the doc versions listed under Doc impact._

- **Four start cards, and the two 공시 cards name a company the server picks per request** (P11.F1,
  the operator's gate report — supersedes P11.S2's six cards and R16 D11's signed strings). The
  bare-접수번호 and 의견 cards are dropped by **the operator's decision**; `security_check` is no card.
- **The picker is `GET /ask/start-cards` → `reads.load_start_cards`, per request** (P11.F1): 검색 =
  most exposable ② filings, 계산 = an ① still exposing `allotment_ratio`; both resolve through
  `find_corps` to one issuer, no Korean on the wire.
- **`/ask` is the start screen's data boundary** (P11.F1, superseding its own 「no data loading」
  docstring): `connection()` + `no-store` + 2.5s, any error or `null` slot falling back **per card** to
  `START_CHIPS_KO` — never a spinner, a blank grid, or three cards where four belong.
- **Chip anatomy: one component, one anatomy** (P11.S1) — conditional mount + absolute popover in both
  placements (R6-4), `.quote*`/`inert` retired, close = 재탭 + outside press + Esc, `fit()` clamps and
  flips up. **Its ground is opaque — the phase's one deviation from R16** (`#0e1a15` +
  `--border-strong` + `--panel-glow`; the 2px `--live` edge and 180px cap stand), **told to the
  operator at the gate**.
- **The operator contact is published in the agent's answer and the footer, at their instruction**
  (P11.F2), from one `MIJUAL_OPERATOR_CONTACT` in the gitignored `.env`, which must be set wherever the
  API runs. **The footer half is an operator override of R8 §4** — phone mono, email sans, in the
  existing 자료/© row, no second row, no invented label — recorded as one in `Footer.tsx`.
- **One string, split on the server; the chrome reads it from the API** (P11.F2): `GET /site/contact`,
  read by the **root layout** because `SiteChrome` is a client component, `revalidate: 600` + 2s.
  Unset or cold-and-unreachable renders **no contact line at all**; with a warm ISR entry the footer
  keeps the last-known values while the API is down (P11.REVIEW, 3rd pass — the cache doing its job).
- **The published contact is public by decision, not a secret** (P11.REVIEW) — its text is in the repo
  too, so 「travels in no commit」 is true of `.env` the *file*, not the value. **Four tracked files
  carry it**, not one: `tests/test_web_site.py` (pins it), `web/site.py` and `Footer.tsx`
  (docstrings), `lib/identicon.test.ts` (a P8 sample). The three real keys still scan **0 hits**.
- **`<html>` carries `suppressHydrationWarning` — scoped and deliberate** (P11.F3). Chrome writes
  `__gchrome_remoteframetoken` onto `<html>` before React hydrates and nothing server-side stops it, so
  the flag silences **the browser, not the product**. Covering that element only, it also hides a real
  `lang`/font mismatch — accepted, all three are literals. **Everything below still reports**, proved
  twice with controls (F3, and independently at the 3rd-pass review).
- **`/_not-found` is request-time; no HTML route is prerendered any more** (P11.F3). It renders
  `usePathname()` via `RequestedPath`, so the build baked Next's literal `/_not-found` into the HTML:
  readers saw a **wrong address** and React threw **#418 (text)**. `connection()` renders their own
  path on the first paint. The table is **16 `ƒ` + 3 `○` icon files = 19 entries** (P11.REVIEW,
  3rd pass — F3's 「19 `ƒ`」 miscounted; the substance was right).
- **The root layout's cached contact read is *not* a hydration hazard** (P11.F3, settling the F2
  suspicion): **19,720 documents** against an adversarial upstream, across a fetch *and* an ISR
  revalidation, **0 torn**. Do not re-open without new evidence.
- **Aside is installed and signed in on this machine** (P11.REVIEW, 3rd pass — the six earlier slices'
  「not installed」 is stale). `aside repl` / `aside exec` drive the desktop viewport; Aside exposes no
  viewport control, so **≤767 still goes through the Chrome-device-metrics fallback**. Recorded
  durably in `qa.md`'s P11 block.

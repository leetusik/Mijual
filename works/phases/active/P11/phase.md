- **Four cards; the two 공시 cards name a company the server picks per request** (P11.F1, on the
  operator's gate report — supersedes P11.S2's six-card set and R16 D11's 「4장 as signed strings」).
  검색 · 계산 (templates with a company slot in `copy.ts`) · 포트폴리오 · 연락처 (static). Dropped: the

  의견 `save_feedback` card (undemonstrated **by the operator's decision**). `security_check` is still
  not a card; R16 D11's set-level rules are enforced by the picker, not an author.
- **The picker: `GET /ask/start-cards` → `reads.load_start_cards`, per request** (P11.F1). 검색 = the
  issuer with the most exposable ② filings; 계산 = an ① still exposing an `allotment_ratio` before its
  deadline (D-20…D-60, single-① issuer, most headroom). Both names must resolve through the agent's
  own `find_corps` to exactly one issuer; the slots avoid each other's company; no Korean on the wire;
  `null` = none today.
- **The `/ask` route is the start screen's data boundary** (P11.F1, superseding its own 「no data
  loading」 docstring): `connection()` + `cache: "no-store"` keep it request-time in the **production**
  build (`/ask` is `ƒ Dynamic`, was `○ Static`); a 2.5s timeout, any error and a `null` slot fall back
  **per card** to `START_CHIPS_KO` — never a spinner, a blank grid, or three cards where four go.
- **Chip anatomy: one component, one anatomy** (P11.S1). Conditional mount + absolute popover in both
  placements (R6-4): prose `.citationWrap` = `relative; inline-block`, the row keeps `display:
  contents` and the popover anchors to `.row`, so R16 §2.6's 「행 아래, 블록 전폭」 survives (732px at
  1280). The `.quote*` classes and `inert` are retired. Close = 칩 재탭 + outside press + Esc with
  focus return; no `×`. `fit()` clamps to the nearest clipping box ∩ viewport and flips upward — the
  620px widget thread clips.
- **The popover's ground is opaque — the phase's one deviation from R16.** `--surface-inset` was
  signed for an *in-flow* panel; as an overlay it lets the sentence read through the evidence. The 2px
  `--live` edge and the 180px cap stand; the fill is `#0e1a15` + 1px `--border-strong` +
  `--panel-glow`. **Told to the operator at the gate.**
- **The 운영자 연락처 is published in both places, at the operator's instruction** (P11.F2).
  `MIJUAL_OPERATOR_CONTACT` (email + phone) lives in the gitignored `.env` and must be set wherever
  the API runs. The agent half needed no code. **The footer half is an operator override of R8 §4**,
  recorded as one in `Footer.tsx`: phone **mono**, email **sans**, joined to the **existing** 자료/©
  row (no second row returns), no invented Korean label. R8's five constants and P8 Q5 untouched.
- **One string, split on the server; the chrome reads it from the API** (P11.F2). `GET /site/contact`
  serves `contact`/`email`/`phone`; the **root layout** reads it — `SiteChrome` is a client component,

  the agent's 「연락처 미설정」 voice.
- **The published contact is public by decision, so it is not a secret** (P11.REVIEW). Its literal

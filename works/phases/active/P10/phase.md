  the repo dir, both `name` fields, the DB credential, "Mijual Design System") — **but any string the
  product says to a user is in**, Korean inside Python included.

  `npm run build && npm run start` on the same origin. `/ops` needs throwaway `MIJUAL_OPS_ID` /
  `MIJUAL_OPS_PASSWORD` on the **API process** — never `.env`. **Aside is not installed here**; every
  slice has used **real Chrome 152 over CDP**, and this machine has **no Screen Recording
  permission**, so nothing here can photograph the OS tab strip.

## Decisions

  prompt strings, reworded not romanized (S3).
- **Binaries — `frontend/public/assets/README.md` is the authority** (S7, rewritten by `P10.F1`).
  Two rules survive every supersession: a class-C derivative is **verified by pixel signature, never
  by sha256**, and no image is ever substituted, generated or placeheld.
- **The phase takes `accept-gate --require`.** **Code doc comments and dev-tooling banners stay** —
  out of scope (**D25**). D23 · D24 · D26 · D27 are filed and open.
- **R17 (`P10.S6` → `P10.S7`) and R18 (`P10.review` → `P10.F1`/`P10.F2`) are landed and versioned**

  favicon's 75 % and the launcher's 84 % **deliberately diverge**; "making them consistent" is the

  (`P10.F3`).** `0.2628·H` aligned the band to the **row's** centre, so it read ~1px low beside the

  alphabetic one (rendered Hangul carries **1.02–1.16px** of ink below it). **h27/h24 and everything
  else R17 signed are untouched.**

## Context

- **Scope: user-facing only.** Code identifiers stay (`src/mijual/`, `MIJUAL_*`, `X-Mijual-CSRF`,
  the repo dir, both `name` fields, the DB credential, "Mijual Design System") — **but any string
  the product says to a user is in**, Korean inside Python included. Comments/docstrings are
  documentation (see Decisions). The name is uniformly the **unspaced `주주의관제탑`** — no spaced
  variant, **no latin mark**. **Round 2 adds a design round** (`intent.md` § Design Style).
- **Operator runtime** — `docs/current/operations.md` `## Operator Runtime`, no `UNFILLED`:
  `make stack-up`; dev `next dev` at `http://127.0.0.1:3000`; Chrome desktop on this Mac + a mobile
  viewport; **and additionally** `npm run build && npm run start`. **`make stack-up` fails at
  `db-up`** — 5433 is held by `changple_web_dev_postgres`, never to be stopped. The way through
  (same image + volume on **5434** via an **`!override`** fragment; `/ops` needs credentials `.env`
  lacks) is versioned in **`operations.md` § Local Development**.

## Decisions

  `COPYRIGHT_KO`, both `metadata.title`s, `OPS_MARK`); S3 the product-name prose.

- **Dev-tooling banners left unchanged (P10.REVIEW).** Not a product surface, and the same terminal

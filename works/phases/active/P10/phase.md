## Context

- **Scope: user-facing only.** Code identifiers stay (`src/mijual/`, `MIJUAL_*`, `X-Mijual-CSRF`,
  the repo dir, both `name` fields, the DB credential, "Mijual Design System") — **but any string the
  product says to a user is in**, Korean inside Python included. The name is uniformly the **unspaced
  `주주의관제탑`** — no spaced variant, **no latin mark**. **Round 2 added a design round**
  (`intent.md` § Design Style, `paired`, one pair).
- **Operator runtime** — `operations.md` `## Operator Runtime`, no `UNFILLED`. **`make stack-up`
  works** (web **3010** / API **8010** / Postgres **5434**); browse **`http://127.0.0.1:3010`**,
  production `npm run build && npm run start` on the same origin. `/ops` needs throwaway
  `MIJUAL_OPS_ID` / `MIJUAL_OPS_PASSWORD` on the **API process**. **Aside is not installed here**;
  the fallback is real Chrome over CDP.

  reproduce in the product (P10.REVIEW, again at `P10.F1`).** (1) **The footer reservation is 108px,
  not 84** — `.content` and `.inner` share one element and `.content` sets the `padding-inline`

  `html:root` (not `:root`) for the font tokens, since React puts the linked `tokens.css` *after* the
  bundle CSS; and `.inner:global(.content)` (not `.inner`) for the corner reservation.
- **The mockup gate was waived by the operator** ("no mockup, just apply directly") for R17 and R18,

  `public/assets/README.md`, the authority. **Not to be touched:** every vertical constant

  and launcher deliberately diverge, and that divergence is the record.
- **An active tab reserves its own 600 width — the rule on two surfaces now (`P10.F2`).** Label and
  a `visibility: hidden` `::after` twin (`attr(data-label)`, 600) share one `inline-grid` cell, so

  reasoned: under `opacity: 0` the AX tree names the link **`AI 질문 AI 질문`**, read twice (all six
  `/ops` tabs likewise). The mobile sheet is excluded (full-width rows shove nothing). **`/ops`

  pushes the last to `right: 439.88` in 390px. Landing's `Board.module.css` still has the defect.

  `slices/P10.F1/result.md` §6.

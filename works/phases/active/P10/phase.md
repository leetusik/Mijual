## Decisions

- **S2/S3 string split (S2):** S2 owned the identity strings bound to the mark (`BRAND_ALT_KO`,
  `COPYRIGHT_KO`, both `metadata.title`s, `OPS_MARK`); S3 the product-name prose.
- **The assistant's own name was a third spelling, 미주얼 (S3)** — invisible to the decomposition's
  `미주알` grep. **13 live prompt strings** swapped, reworded rather than romanized.
- **Binaries — `frontend/public/assets/README.md` is the authority**, rewritten by S7 for the second
  delivery. Two rules survive every supersession: a class-C derivative is **verified by pixel
  signature, never by file sha256**, and no image is ever substituted, generated or placeheld.
  *(Both re-derived independently at `P10.REVIEW` — signatures match, symbol re-trims to
  `222x165+0+0`; for the counter guard see the R18 decision below.)*
- **The phase takes `accept-gate --require`** — it changes what the operator sees on every page.
- **Code doc comments and dev-tooling banners stay (P10.REVIEW).** Out of scope; a sweep is its own
  job. **D25** (comments + banners), **D23** (P4 mail subject), **D24** (`/ops` 390) — all filed.
- **R17 landed (P10.S6), `P10.S7` applied it, `P10.REVIEW` re-measured it in the product.** Record:
  `docs/reference/design/rounds/17-brand-mark-launcher/output/`. Still current: wordmark **nav h27 /
  footer h24**, ink-aligned `-7px` / `-6px` (R2's h19/h17 retired) · launcher = **32×32 sparkle
  painted by CSS `mask` + `currentColor`**, Saturn and both animations deleted, **0 animations in all
  six states**, ink width **84%** · symbol a **first-class mark**, ink **222×165**. **Superseded by
  R18:** the wordmark box and both favicon rules. **Token delta: None. New strings: 0.**
- **The launcher's motion exception expired; the product is not motion-free (P10.S7, confirmed).**
  R2's cosmos backdrop (`drift`/`twinkle`/`shoot`), Hero's `orbit` and the streaming caret still
  animate. Say "the launcher's exception expired". Under `prefers-reduced-motion` the whole document
  reports **zero** animations.
- **`P10.S7` corrected two arithmetic errors in the landed R17 record without editing it; both
  reproduce in the running product (P10.REVIEW).** (1) **The footer reservation is 108px, not 84.**
  `Footer.tsx` puts `.content` and `.inner` on one element and `.content` sets the `padding-inline`
  **shorthand**, so the reservation *replaces* 24px and clearance is `P − 92`; at 84px **8px of
  의견 보내기 stayed under the launcher** — the dead interaction R17 existed to fix, still dead.
  At 108 the button opens its panel at every width tested, dev **and** production.
  (2) **R17's absolute nav numbers are 0.5px high** — it computes from a 52px content box; the bar is
  52px *border-box* with a 1px rule → **51px**. The relationship holds; no fix. Both re-measured at
  the re-review; the tables are in `slices/P10.REVIEW/result.md`.
- **Two cascade traps make correct-looking CSS inert — do not "simplify" either selector.**
  `html:root` (not `:root`) for the font tokens, because React places the linked `tokens.css` *after*
  the bundle CSS (confirmed: `tokens.css` is last in both runtimes); and `.inner:global(.content)`
  (not `.inner`) for the corner reservation. Both commented in place.
- **The mockup gate was waived by the operator** ("no mockup, just apply directly"), so the phase's
  acceptance gate is R17's only running review, and the card regroup waits there (`SIGNOFF.md` R17).
- **R18 (`P10.review`) supersedes three R17 values — and the operator ran that design session
  themselves**, during the open gate, so there is no orchestrator handoff. Record:
  `docs/reference/design/rounds/18-p10-review/` (`output/handoff.md` **read-only**;
  `output/VERIFICATION.md` = the orchestrator's pre-apply re-measurement). Superseded: wordmark
  **1292×371 → 1247×371** (a quarter-em space — 45 dead columns cut from inside a **70-column,
  full-height transparent band**) · favicon **transparent tile + `#2b8e6c` ink at 75%** (was opaque
  `#0a1310` + white at 84%) · nav and `/ops` active tabs now **reserve the 600 width**. **Unchanged
  and not to be touched:** every vertical constant (`INK_OFFSET 0.2628·H`, `translateY(-7/-6px)`,
  band centre 76.28%) and **the launcher's `mask-size: 84%`** — favicon and launcher deliberately
  diverge, and that divergence is the record. **The mockup was waived again**, so the acceptance
  gate is R18's only running review too.
- **R18's §① verification table carries a guard that cannot fail — do not copy it into the README.**
  "opaque near-white = 0" on an **all-white** derivative always returns the opaque count (69,630).
  The README's own wording is fine because it is scoped *inside 「의」's ㅇ on the source*. The
  durable checks are the **two counter islands** (`50×46 at (402,226)` → 481 and `69×15 at
  (969,335)` → 15, both unchanged) and the **alpha-splice hash**. See `output/VERIFICATION.md` §2.
  Every prescription in R18 reproduced exactly; only this one procedure is wrong.

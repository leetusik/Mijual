## Context

- **Scope: user-facing only.** Code identifiers stay (`src/mijual/`, `MIJUAL_*`, `X-Mijual-CSRF`,
  the repo dir, both `name` fields, the DB credential, "Mijual Design System") — **but any string the
  product says to a user is in**, Korean inside Python included. The name is uniformly the **unspaced
  `주주의관제탑`** — no spaced variant, **no latin mark**. **Round 2 added a design round**
  (`intent.md` § Design Style, `paired`, one pair).
- **Operator runtime** — `operations.md` `## Operator Runtime`, no `UNFILLED`. **`make stack-up`
  works** (web **3010** / API **8010** / Postgres **5434**). Browse **`http://127.0.0.1:3010`**;
  production is `npm run build && npm run start`, same origin. `/ops` needs throwaway
  `MIJUAL_OPS_ID` / `MIJUAL_OPS_PASSWORD` on the **API process** — `operations.md` § Local
  Development. **Aside is not installed here**; the fallback is real Chrome over CDP.

- **The phase takes `accept-gate --require`** — it changes what the operator sees on every page.
- **Code doc comments and dev-tooling banners stay (P10.REVIEW)** — out of scope. **D25**, **D23**
  (P4 mail subject), **D24** (`/ops` 390) — all filed.
- **R17 landed (P10.S6), applied by `P10.S7`, re-measured by `P10.REVIEW`.** Record:
  `.../rounds/17-brand-mark-launcher/output/`. Still current: wordmark **nav h27 / footer h24**
  ink-aligned `-7/-6px` (R2's h19/h17 retired) · launcher = **32×32 sparkle painted by CSS `mask` +
  `currentColor`**, Saturn and both animations gone, **0 animations in all six states**, ink **84%** ·
  symbol a **first-class mark**, ink **222×165**. **Superseded by R18:** the wordmark box and both
  favicon rules. **Token delta: None. New strings: 0.**
- **The launcher's motion exception expired; the product is not motion-free (P10.S7).** R2's cosmos
  backdrop, Hero's `orbit` and the streaming caret still animate — say "the launcher's exception
  expired". Under `prefers-reduced-motion` the whole document reports **zero** animations.
- **`P10.S7` corrected two arithmetic errors in the landed R17 record without editing it; both
  reproduce in the product (P10.REVIEW, and again at `P10.F1`).** (1) **The footer reservation is
  108px, not 84** — `.content` and `.inner` share one element and `.content` sets the
  `padding-inline` **shorthand**, so the reservation *replaces* 24px and clearance is `P − 92`; at 84
  **8px of 의견 보내기 stayed under the launcher**. At 108 the button opens its panel at every width,
  dev **and** production. (2) **R17's absolute nav numbers are 0.5px high** — it computes from a 52px
  content box; the bar is 52px *border-box* with a 1px rule → **51px** (so the h27 band centre is
  25.60, not 26.10, against a 25.5 optical centre — unmoved by R18). Tables:
  `slices/P10.REVIEW/result.md`.
- **Two cascade traps make correct-looking CSS inert — do not "simplify" either selector.**
  `html:root` (not `:root`) for the font tokens, because React places the linked `tokens.css` *after*
  the bundle CSS; and `.inner:global(.content)` (not `.inner`) for the corner reservation.
- **The mockup gate was waived by the operator** ("no mockup, just apply directly") for R17 and
  again for R18, so the acceptance gate is their only running review (`SIGNOFF.md`).
- **R18 (`P10.review`) supersedes three R17 values — the operator ran that design session
  themselves** during the open gate, so there is no orchestrator handoff. Record:
  `.../rounds/18-p10-review/` (`output/handoff.md` **read-only**; `output/VERIFICATION.md` = the
  pre-apply re-measurement). Superseded: wordmark **1292×371 → 1247×371** (45 dead columns of a
  quarter-em space, cut from inside a **70-column, full-height transparent band**) · favicon
  **transparent tile + `#2b8e6c` ink at 75%** (was opaque `#0a1310` + white at 84%) · nav and `/ops`
  active tabs **reserve the 600 width**. **Unchanged and not to be touched:** every vertical constant
  (`INK_OFFSET 0.2628·H`, `translateY(-7/-6px)`, band centre 76.28%) and **the launcher's
  `mask-size: 84%`** — favicon and launcher deliberately diverge, and that divergence is the record.
- **Every R18 *prescription* reproduced exactly; three of its *verification procedures* are wrong
  (`P10.F1` applied §①③④ and fixed all three in the README; records unedited).** (a) "opaque
  near-white = 0" over an all-white derivative is just the opaque count (69,630) and can never fail —
  use the **two counter islands** (`50×46+402+226` → 481, `69×15+969+335` → 15, unchanged) and the
  **alpha-splice hash** `d90e9827…`. (b) Aspect is **3.3612**, not 3.3603 → render widths **90.75 /
  80.67px**; Chrome reports 90.75×27 and 80.66×24. (c) §③'s ink check reads pixel (0,0) — transparent
  canvas, always `0,0,0`; count visible px that are not `#2b8e6c` (0 in all three).

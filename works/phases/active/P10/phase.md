## Notes for later slices

- **`P10.S7` corrected two arithmetic errors *in the landed R17 record*, without editing it.** Both
  measured, in `slices/P10.S7/result.md` §2:
  1. **the footer reservation is 108px, not 84px.** R17 §1 states *both* `92px` and `84px`; the
     launcher is `right:24px` so it occupies **92px** from the edge and clearance is `P − 92`. With
     84px, **exactly 8px** of 의견 보내기 stayed under it and every hit-probe returned the launcher —
     the dead interaction R17 existed to fix, still dead. 108 = 68 + 24 + 16.
  2. **its absolute nav numbers are 0.5px high** (it computes from a 52px content box; `.bar` is
     52px *border-box* with a 1px rule → 51px). The *relationship* holds to 0.1px. No fix.
  **(from P10.S7, for P10.REVIEW)**
- **Two cascade traps made correct-looking CSS inert**, invisible in source, caught only in a
  browser: `tokens.css` is a `<link>` React places **after** the bundles, so the font override needs
  `html:root`; and `.content` sets the `padding-inline` **shorthand** later in bundle order than
  `Footer.module.css`, so the reservation needs `.inner:global(.content)`. Both commented in place —
  **do not "simplify" either selector**. **(from P10.S7, for P10.REVIEW)**
- **The `/ops` bar needs throwaway `MIJUAL_OPS_*` or you only ever see the door** — the gate
  walkthrough needs that step. Also: the stack now runs on **3010 / 8010 / 5434** (commit `c8606d0`),
  so `make stack-up` works and the old 5433 `!override` recipe is obsolete. **(from P10.S7)**

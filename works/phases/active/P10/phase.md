  the repo dir, both `name` fields, the DB credential, "Mijual Design System") — **but any string the

  `MIJUAL_OPS_PASSWORD` on the **API process** — never `.env`. **Aside is not installed here**; every
  slice has used **real Chrome 152 over CDP**, and this machine has **no Screen Recording

## Decisions

- **The assistant's own name was a third spelling, 미주얼** — invisible to a `미주알` grep; 13
  prompt strings, reworded not romanized (S3).
- **Binaries — `frontend/public/assets/README.md` is the authority** (S7, rewritten by `P10.F1`).
  Two rules survive every supersession: a class-C derivative is **verified by pixel signature, never
  by sha256**, and no image is ever substituted, generated or placeheld.
- **The phase takes `accept-gate --require`.** **Code doc comments and dev-tooling banners stay** —
  out of scope (**D25**). D23 · D24 · D26 · D27 are filed and open.
- **R17 and R18 are landed and versioned** — `decisions.md` D-28/D-29, `frontend.md` v0010; round
  records under `docs/reference/design/rounds/{17-brand-mark-launcher,18-p10-review}/` (read-only).
  Still current: the launcher as a 32×32 CSS-`mask` sparkle with **0 animations** and
  **`mask-size: 84%`** — the favicon's 75 % and the launcher's 84 % **deliberately diverge**;
  "making them consistent" is the regression.
- **The mark's vertical law is text-referenced — the operator superseded R17's `0.2628·H` at the
  round-3 gate** (`P10.F3`; versioned at r4 as `decisions.md` **D-30** + `frontend.md` v0011). Band
  Hangul ink bottom on the neighbouring Hangul's → **`INK_OFFSET_PX = {27: 8, 24: 6}`** (nav
  `-7 → -8`; footer re-derived, unchanged). Re-measured independently at r4 in dev **and** the
  production build, 1280 + 390: band bottom **31.000** vs labels **30.875–31.125** (|Δ| ≤ **0.125**),
  footer Δ **0.00–0.28**, **top clearance 4.00px**, 390 vs 메뉴 **+0.083–0.125**. **Rejected:** the
  shared optical line (7.38–7.69 by label — undecidable, and **7** against pure-Hangul labels, i.e.
  no change). "Baseline" = **Hangul block bottom**, never the alphabetic one (rendered Hangul carries
  **1.02–1.16px** of ink below it — reproduced at r4). **h27/h24 and everything else R17 signed are
  untouched.**
- **`P10.S7` corrected two arithmetic errors in the signed R17 record without editing it; both
  reproduce:** the footer reservation is **108px, not 84** (`.content` sets the `padding-inline`
  *shorthand*, clearance `P − 92`), and **R17's absolute nav numbers are 0.5px high** (52px
  *border-box* → **51px content**).
- **Two cascade traps make correct-looking CSS inert — never "simplify" either selector:**
  `html:root` (not `:root`) for the font tokens; `.inner:global(.content)` (not `.inner`) for the
  corner reservation.
- **The mockup gate was waived for R17 *and* R18** ("no mockup, just apply directly"), so the
  acceptance gate is the operator's only running review (`SIGNOFF.md`).
- **Six signed values turned out wrong. Four shipped checks *could not* fail; the fifth *could*, and
  passed anyway, because it was pointed at the wrong reference.** R17 shipped three bad values;
  R18's three *procedures* were caught by `P10.F1`; r3 found a fourth in this phase's own round-1
  doc consolidation; r4's is R17's alignment reference itself. **The rule this phase leaves behind:
  a guard is only a guard if some input makes it report failure — *and only the right guard if it is
  pointed at what the operator is actually looking at.*** `P10.F3`'s check honours both: repainted at
  R17's `-7` it FAILs on every nav and footer surface, worst **1.125**, dev and production (re-run at
  r4 by an independent scanner).
- **An active tab reserves its own 600 width — two surfaces (`P10.F2`).** Label + a
  `visibility: hidden` `::after` twin (`attr(data-label)`, 600) in one `inline-grid` cell.
  **Never `opacity: 0`** (under it the AX tree reads every label twice — re-proved at r4).
  `/ops` takes the rule **without `white-space: nowrap`**; sheet and landing board stay outside it.

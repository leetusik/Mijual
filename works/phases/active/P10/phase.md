## Context

- **Scope: user-facing only.** Code identifiers stay (`src/mijual/`, every `MIJUAL_*`,
  `X-Mijual-CSRF`, the repo dir, both `name` fields, the design project's own name). **But any
  string the product says to a user is in**, Korean inside Python included. Comments and
  docstrings are documentation and **no slice owns them** (see the REVIEW note below).
- **The name is uniformly the unspaced `주주의관제탑`** — no spaced variant, **no latin mark**:
  `MIJUAL` / `MIJUAL OPS` are retired with no romanized replacement. **No design round** — the
  operator delivered a finished mark; apply-only. Deadline: P4 ships **2026-09-07 10:00**.
- **Operator runtime is declared** — `docs/current/operations.md` `## Operator Runtime`, no
  `UNFILLED`: `make stack-up`; dev `next dev` at `http://127.0.0.1:3000`; Chrome desktop on this
  Mac plus a mobile viewport; **and additionally** `npm run build && npm run start`. **No slice
  may verify anywhere else.**
- **`make stack-up` still fails at `db-up`** — 5433 is held by `changple_web_dev_postgres`, an
  unrelated project that **must never be stopped**. The way through (same image + volume on
  **5434** via an **`!override`** fragment) is written out as **the operator's own gate recipe**,
  with restore, in `slices/P10.S5/result.md` §0 — which also records that
  `MIJUAL_OPS_ID`/`_PASSWORD` are unset in `.env`, so `/ops` shows only the door without them.

## Decisions

- **S2/S3 string split, settled at S2.** S2 owned the identity strings bound to the mark
  (`chrome/copy.ts` `BRAND_ALT_KO` + `COPYRIGHT_KO`, both `metadata.title`s, `ops/copy.ts`
  `OPS_MARK`); S3 owned the product-name prose everywhere else.
- **The assistant's own name is user-facing — and it was a third spelling (S3).** The agent's
  prompt called the product **미주얼** (얼), which the decomposition's `미주알` grep never saw. The
  prompt decides the name the model *says*, so **13 live strings** were swapped (9
  `instructions.py`, `tools.py` `DATA_BOUNDARY`, 3 `declarations.py`). The product had been
  shipping two spellings of its own name; the rename normalises that. Comments keep 미주얼.
- **The latin mark is reworded, never substituted (S3)** — there is no romanized replacement:
  `instructions.py:52` dropped the `(Mijual)` gloss outright, `declarations.py:139` used *Mijual*
  as an English noun and became "this product itself".
- **`instructions.py` is a signed static cache prefix** — its order is a cache key. S3 changed only
  names and reflowed nothing; the one-time implicit-cache invalidation is accepted.
- **Binaries, settled by S1/S2** (method: `frontend/public/assets/README.md`,
  `slices/P10.S1/result.md`): natural pair **1213x319**; the white variant is a repo-generated
  derivative **verified by pixels, not sha256** (never "fix" a hash by re-deriving); black is
  light-surfaces-only and referenced by no code; `WORDMARK_WHITE` / `WORDMARK_NATURAL`.
- **The phase takes `accept-gate --require`** — it changes what the operator sees on every page.
- **S5 verified the phase end-to-end and fixed nothing.** Every surface holds in **dev and the
  production build, desktop and 390px**: marks painted, both titles in the real tab, disclaimer
  boxes unchanged to the hundredth of a pixel, retired assets 404, zero live `mijual-*.png`
  references, no fringing, and the live agent naming itself correctly in **both** runtimes
  (production was untested before today). `slices/P10.S5/result.md` is the walkthrough's source.

## Operator Questions

- **The ops mark's treatment — measured at S2, and it does not hold.** The string is now
  `주주의관제탑 운영` (implemented; the operator was told and did not object but never confirmed
  it in words). `Ops.module.css` `.mark`/`.doorMark` are **untouched** and still set
  `--font-mono` + `letter-spacing: 0.08em`, per R7's "an identifier, so it stays raw and mono".
  What renders (CDP `CSS.getPlatformFontsForNode`, both nodes, dev and production): **IBM Plex
  Mono SemiBold — 1 glyph (the space)**; **Apple SD Gothic Neo SemiBold — 8 glyphs (all the
  Hangul)**. So mono now styles exactly one character. Visible consequences: the 관제탑␣운영 gap
  reads as a double space; the mark's face is the **OS's**, so it differs off macOS; and in the
  bar it sits among Pretendard Korean tab labels and no longer reads as an identifier at all,
  while the `mijual:lock:pipeline free` chip beside it still does. **S2's recommendation, not
  taken:** keep the string, drop `--font-mono` + tracking from those two rules and let
  Pretendard 600 carry it. Signed styling, so the operator decides. (from P10.DECOMP, measured
  by P10.S2)
- **The signed chrome heights — h19/h17 implemented, measured, hierarchy inverted.** Nav
  `<img>` computes to **72.24x19** with a **9.65px** Korean band; footer **64.64x17** with
  **8.63px**. The adjacent nav label is 13.5px and the footer source line 12px, so the mark is
  **0.72x** the type beside it — where the retired ring was **1.07x**. Not illegible (clean at
  retina 2x, no fringing), but the brand is now the smallest text in its own bar. Layout is
  fine: the slot narrows 119.6 → 72.24px, the 24px gap is unchanged, nothing wraps or
  overflows at 1280 or 390. **S2's recommendation, acceptable in one word: `h27` nav / `h24`
  footer** — band 13.7/12.2px, parity with the adjacent type, boxes still narrower than the
  ring's. Raising it deviates from a signed number, so the operator decides at the gate.
  Note also: box-centring puts the glyph band 4.18px below the 52px bar's optical centre (6.14
  at h27), because the ink is bottom-half only. (from P10.DECOMP, measured by P10.S2)
- **The favicon: the mark does not reduce.** At 32px it is illegible mush. **S2 shipped nothing
  and cropped nothing** and confirmed the pre-existing state is intact: no `app/icon.*`, no
  `favicon.ico`, no `manifest`, no `openGraph`, no `icons` key, and zero `link[rel*=icon]` in
  dev or production. The assets README's rule forbids substituting, generating or placeholding
  an image. The operator chooses: (a) ship no favicon, as today; (b) supply a square symbol
  export; or (c) authorize cropping the sparkle cluster as a symbol. (from P10.DECOMP)
- **P4's mail subject still carries the retired name.** The signed R5 spec, quoted in
  `src/mijual/mail.py:14` as `[미주알] {jongmok} — {magamname} D-{n} ({date})`, is unimplemented
  and out of this phase's scope. P4 will render `[미주알]` unless the operator re-signs the
  subject. (from P10.DECOMP)
- **Dev-tooling banners: `DECOMP` put them in scope, S4's plan took them out — left unchanged.**
  `Makefile:1` (`# Mijual dev stack.`), `Makefile:110`, `compose.yaml:1`. But `make stack-status`
  prints `── mijual dev stack ──` to the operator's own terminal, so "mentions it in passing" is

- **The `/ops` bar mark stacks one syllable per line at 390px (S5).** `.mark` computes to

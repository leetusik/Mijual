## Context

- **Scope: user-facing only.** Code identifiers stay (`src/mijual/`, `MIJUAL_*`, `X-Mijual-CSRF`,
  the repo dir, both `name` fields, the DB credential, "Mijual Design System") — **but any string the
  product says to a user is in**, Korean inside Python included. The name is uniformly the **unspaced
  `주주의관제탑`** — no spaced variant, **no latin mark**.
- **Operator runtime** — `operations.md` `## Operator Runtime`, no `UNFILLED`. **`make stack-up`
  works** (web **3010** / API **8010** / Postgres **5434**); browse **`http://127.0.0.1:3010`**,
  production `npm run build && npm run start` on the same origin. `/ops` needs throwaway
  `MIJUAL_OPS_ID` / `MIJUAL_OPS_PASSWORD` on the **API process** — never `.env`. **Aside is not
  installed here** (not on `PATH`, no app bundle); the fallback every slice has used is **real
  Chrome 152 over CDP**, and this machine has **no Screen Recording permission**, so no process here
  can photograph the OS tab strip.
- **Decomposition.** Round 1: five middle slices on one rule — the slice that produces the binary
  must not decide whether it reads. Round 2: one design round (`P10.S6`) + one apply slice
  (`P10.S7`) — *"just one design round and then do rest."* Round 3: R18's two fix slices.

## Decisions

- **S2/S3 string split (S2):** S2 owned the identity strings bound to the mark (`BRAND_ALT_KO`,
  `COPYRIGHT_KO`, both `metadata.title`s, `OPS_MARK`); S3 the product-name prose.
- **The assistant's own name was a third spelling, 미주얼 (S3)**, invisible to the `미주알` grep;
  **13 live prompt strings** swapped, reworded rather than romanized.
- **Binaries — `frontend/public/assets/README.md` is the authority** (S7, rewritten by `P10.F1`).
  Two rules survive every supersession: a class-C derivative is **verified by pixel signature, never
  by file sha256**, and no image is ever substituted, generated or placeheld. All four R18
  derivatives re-derive identically (`-metric AE` = 0).
- **The phase takes `accept-gate --require`.** **Code doc comments and dev-tooling banners stay** —
  out of scope (**D25**). **D23** (P4 mail), **D24**/**D27** (`/ops` layout), **D26** (launcher open
  state) all filed and open.
- **R17 (`P10.S6`, applied by `P10.S7`) and R18 (`P10.review`, applied by `P10.F1`/`P10.F2`) are
  both landed, re-measured, and now versioned.** The durable record is **`decisions.md` D-28 +
  D-29** and **`frontend.md` v0010**; the round records are
  `docs/reference/design/rounds/{17-brand-mark-launcher,18-p10-review}/` (read-only). Still current
  and *not* superseded by R18: every vertical constant (`INK_OFFSET 0.2628·H`,
  `translateY(-7/-6px)`, band centre **25.60** at h27), the launcher as a 32×32 CSS-`mask` sparkle
  with **0 animations**, and its **`mask-size: 84%`** — the favicon's 75 % and the launcher's 84 %
  **deliberately diverge**, and "making them consistent" is the regression.
- **`P10.S7` corrected two arithmetic errors in the signed R17 record without editing it; both
  reproduce in the product** (re-measured at every review since). (1) **the footer reservation is
  108px, not 84** — `.content` sets the `padding-inline` *shorthand* on the shared element, so
  clearance is `P − 92` and at 84 **8px of 의견 보내기 stayed under the launcher**; (2) **R17's
  absolute nav numbers are 0.5px high** (52px *border-box*, 1px rule → 51px content).
- **Two cascade traps make correct-looking CSS inert — do not "simplify" either selector.**
  `html:root` (not `:root`) for the font tokens; `.inner:global(.content)` (not `.inner`) for the
  corner reservation.
- **The mockup gate was waived by the operator for R17 *and* R18** ("no mockup, just apply
  directly"), so the acceptance gate is their only running review (`SIGNOFF.md`).
- **Five signed values in this phase turned out wrong, and three of them were checks that could not
  fail.** R17 shipped three (the filled counter, the symbol's ghost ink, the 84px reservation);
  R18's three *procedures* were caught by `P10.F1` and re-proved at `P10.REVIEW` round 3 **against
  deliberately corrupted inputs**: the near-white guard (69,630, never 0 — replaced by the two
  counter islands 481/15 and the alpha-splice hash `d90e9827…`), the aspect (**3.3612**, not 3.3603
  → **90.75 / 80.67**, Chrome paints 90.75×27 / 80.66×24), and the tile ink check (reads pixel (0,0)
  on transparent canvas — replaced by "0 visible px that are not `#2b8e6c`"). **Round 3 found a
  fourth of the same family, in this phase's own round-1 doc consolidation** — `frontend.md`'s
  "opaque near-white must be 0 … measured on the landed files" is 0 only on the *dark source*; it is
  69,630 on the shipped white derivative and 1,824 on the symbol. Rewritten in `frontend.md` v0010.
  **The standing rule this phase leaves behind: a guard is only a guard if some input makes it
  report failure, and an unscoped copy of a scoped check is the failure mode that produced two of
  the three.**
- **An active tab reserves its own 600 width — the rule on two surfaces now (`P10.F2`).** Label and
  a `visibility: hidden` `::after` twin (`attr(data-label)`, 600) share one `inline-grid` cell.
  **`visibility: hidden`, never `opacity: 0`** — under `opacity: 0` the AX tree reads every label
  twice (reproduced independently at the review, with the control). `/ops` takes the rule **without
  `white-space: nowrap`** (at 390 nowrap pushes the last tab to `right: 439.88` in a 390px viewport
  and buys no reservation there anyway). Mobile sheet and landing board deliberately outside it.

## Notes for later slices

**(from P4.DECOMP, for P4.S1/S3/S4) — the "no harm" contract on a box that already has a front door**

- No systemd there, and **Mijual must not install nginx**. `~/projects/personal/edge/edge/` (note the doubled path) owns `:80`/`:443` for every co-tenant: pinned `nginx:1.27-alpine`, `edge-nginx`, read-only `conf.d` + `certs`.
- Mijual's whole edge footprint is **one new file** in that `conf.d/` (`jujutower.conf`) plus this zone's cert pair in `certs/`. Author it here as `deploy/edge/jujutower.conf` and copy it across; edge-repo changes are outside Mijual's git, so commit only this repo.
- **Never `up`, `restart` or `--force-recreate` edge-nginx** — it drops the shared-network attachment and cascades into every co-tenant. A config change is: drop the file → `nginx -t` → `nginx -s reload`, which `edge/{validate,stage,deploy}.sh` encode with `nginx -t` as a hard gate.
- **Containers, not systemd**, per `hi2vi_web/compose.prod.yml`: `restart: unless-stopped`; a healthcheck (also the rollback trigger); **`expose:`, never `ports:`** (host ports collide with co-tenants); `networks: {external: true}` so `docker compose down` cannot delete a shared network. Rollback is a tag flip: tag `:previous` *before* building, health-gate after `up -d`, retag and re-up on failure.
- `next.config.ts` needs `output: "standalone"`. Zone/upstream/`map` names are **global across the whole `conf.d/` tree** (a duplicate fails `nginx -t` for every site), so namespace everything `jujutower_*`.
- **Copy `vocky.conf`, not `hi2vi.conf`** (same FastAPI + Next shape). Three outage-grade rules: (1) variable `proxy_pass` + `resolver 127.0.0.11` — a literal `proxy_pass http://svc:3000` resolves once at config load and 502s forever after a recreate; (2) nginx inherits the server-level `proxy_set_header` block into a location **only if that location sets none of its own**, so one header inside a location silently drops the whole inherited set; (3) route everything to the **frontend** container and let Next's `/api/*` rewrite reach FastAPI — splitting `/api/` off at nginx changes the origin model and breaks same-origin CSRF.

**(from P4.DECOMP, for P4.S3/S4/S6) — streaming through two proxies, not one**

- `/ask` traverses **Cloudflare → edge nginx → Next → FastAPI**. Copy the streaming directives wholesale from `edge/conf.d/changple-web.conf` `location /bff/` (marked "do not tidy") rather than assembling them.
- **Cloudflare caps an origin response at ~100 s then serves a 524**, whatever nginx's timeout says — one agent turn must stay well under it (`architecture.md` lacks this).
- **No gzip at the origin**: the edge tree disables it (Cloudflare compresses), which is also right for `no-transform`.
- `Cache-Control: no-store, no-transform` and `X-Accel-Buffering: no` must survive **every** hop; idle timeout > ~10 s (no heartbeat, longest observed gap **6.0 s**). Only a real browser reproduces the re-encoding failure; `curl` without `Accept-Encoding` will not.

**(from P4.DECOMP, for P4.S4) — Cloudflare: order is load-bearing, plus prohibitions**

- Order: HTTP-first over grey (DNS-only) → mount the origin cert → enable `:443` → `nginx -t` → reload → DNS to proxied → SSL/TLS **Full (Strict)** → the `:80`→HTTPS redirect **last** → HSTS. Out of order gives an instant 526 or a cached redirect loop; a wrong A record shows as a **522**, not a DNS error.
- Cloudflare prepends its own managed content-signals block to `/robots.txt` — do not duplicate it at the origin. Verify Search Console with a **DNS TXT Domain property** via the Cloudflare integration, not an HTML meta token.
- Anything here calling a Cloudflare-fronted host over `urllib` must send a `User-Agent` or gets `403 error 1010 browser_signature_banned`.

**(from P4.DECOMP, for P4.S1/S4) — production config the live `.env` does not have**

- Eight env vars through a gitignored `.env.prod`, with a committed `.env.prod.example` naming every key: `DATABASE_URL`, `REDIS_URL`, `MIJUAL_SESSION_SECRET`, `MIJUAL_COOKIE_SECURE=1`, `MIJUAL_OPS_ID`, `MIJUAL_OPS_PASSWORD`, `MIJUAL_APP_BASE_URL`, `MIJUAL_API_ORIGIN`.
- **Create `conversation_turn` / `conversation_feedback` before the first question** — no migrations exist, a fresh database has 16 tables not 18, and every `/ask` turn fails at persistence. `create_all` + `ensure_columns` is additive and idempotent (`make db-ensure`).
- **Install a root logging config** or the `▷` agent-spend ledger goes nowhere: the Makefile's API launch inlines it, a bare `uvicorn` entrypoint does not.
- **`MIJUAL_OPERATOR_CONTACT` must be exported where the API runs**, not the frontend — unset is invisible in dev and silently drops the footer links in production.
- **Postgres is net-new on that box** (hi2vi is SQLite, so no backup/restore runbook to lift; `compose.yaml` here is dev-only): the production database, its volume and a restore path are this phase's own work. **No Python lockfile exists** — a reproducible image wants one pinned.
- **No CORS** (CSRF rests on `/api/*` being a same-origin Next rewrite, no preflight); **no third-party origin on any page** (a measured, signed property).
- Ask-limiter and login-attempt state is **per process**: N workers means N× the intended cap.
- The scheduler is **Celery beat + worker on Redis** (`mijual.scheduler`, compose profile `scheduling`; schedule and run-lock key declared exactly once in `mijual.beat`). Production compose must carry beat, worker and Redis, and the D-day send is a new beat task — never a second scheduling mechanism.

## §6 open questions → session decisions (operator form, 2026-08-21)

- **§6.1 · Suppression reason 표기 = raw English 코드 (operator 서명)** — 운영자 전용
  표면에서는 코드가 정직한 표기. 한국어 문구를 만들지 않음; 코드에 없는 카피는 화면에도

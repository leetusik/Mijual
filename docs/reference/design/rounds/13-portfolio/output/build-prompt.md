## 1. D-day 행 — 이 슬라이스의 본체

- `.rowHead`의 `space-between`을 **제거**하고 행 전체를 하나의 그리드로:
  `grid-template-columns:84px minmax(0,1fr) 212px 208px; gap:4px 16px`.
  칩=열1 · 종목명=열2 · 지배 라벨=열3 · 카운트다운=열4(`justify-self:end`).
- 사라질 수 있는 요소가 든 줄은 `min-height`로 컨트롤 높이를 상시 보유한다(금액 줄 =
  `.pmlead`). 조건부 렌더가 레이아웃을 접으면 그것이 깜빡임이다.
- 행 **본문**은 `grid-column:2/-1`. 소멸 금액 줄은 그 안에서 다시
  `minmax(0,1fr) 208px`(같은 gap) — 값의 오른쪽 edge가 위 카운트다운과 한 선.
- 지나간 행의 칩 + 날짜는 **한 줄**(두 줄로 쌓으면 라벨 아래 반칸 구멍). 마지막 트랙은
  가장 긴 칩(「통지 마감 지남 · D+n」) + 날짜가 한 줄에 들어가는 폭이어야 한다.
- 열 머리글·세로선 **금지**(표가 아니다). 섹션 제목은 기존 `//` eyebrow.
- 표면 폭 `max-width:960px`(제품의 값). 앵커 줄은 **블록에 한 번**, 섹션 밖.
- 회귀: 1440/1280/768/390에서 (a) 두 섹션의 모든 행이 같은 4 edge를 갖는지,
  (b) 금액과 카운트다운의 오른쪽 edge가 같은지, (c) 144.7px 들쭉날쭉/584.6px 빈 가운데가
  0인지 측정.

## 2. 보유 종목

- 트랙 `minmax(0,1.15fr) 132px minmax(0,1.5fr) 152px`, 머리글 유지(mono 10).
- 진행 중인 권리 셀 트랙 `52px minmax(0,1fr) auto` — 카운트다운·날짜는 셀 오른쪽 edge에
  정렬(모든 행 한 선).
- 빈 진행 중인 권리 셀 = `.pslot` **파선 하이라인 56px**, `aria-hidden`. 문장 금지,
  파선 상자 금지, `—`/`0건` 금지.
- 인라인 편집: 보유량 셀만 입력으로, 액션 열 `수정·삭제 → 저장·취소` **가로 교체**.
- 삭제: 즉시 + **8초 되돌리기 inset 행**(토스트·모달 금지). 되돌린 행은 새 보유 →
  목록 끝(서버의 `created_at` 순서).
- `?add=`: 종목 칸 프리필 + 보유량 포커스. 이미 담긴 종목이면 그 행의 수정을 연다.

## 3. 알림 설정

- 페이지 첫 행에 레일 `← 보유 종목`(min-height 44px), 제목은 **`h1`**(`h2` 승격).
  페이지에 `h1`은 하나.
- 행 그리드 `104px minmax(0,1fr) auto` — 라벨 / 값 / 액션. 액션 열은 한 edge를 공유
  (변경 · 로그아웃 · 계정 삭제).
- 오류 줄: `authErrorKo(code)` 그대로 = 본문 잉크 한 줄(`.pnerr`), 필드 테두리 무변,
  `--alert` 금지. `invalid_email` 물림은 **의도된 것**.
- 시점 칩: `aria-pressed` 다중선택, **빈 선택은 유효한 설정**(기본값으로 복귀 금지).
- KakaoTalk: 라벨 + `「예정」` + 문장, **인터랙티브 컨트롤 렌더 금지**.
- 계정 삭제: **제자리 무장**(계정 삭제 · 취소, 두 번째 누름이 삭제). 모달 금지.
  **서명된 문장은 무장 상태에서만 렌더**(상시 금지 — 이번 세션 개정).
- 로그아웃 · 계정 삭제 · 취소는 `.pact.wide`(104px 밑바닥) — 같은 상자 크기.

## 4. 샘플 모드

- 배너 하나, 종목 추가 없음, 보유량 캡션 없음, 체크 캡션 `본인 표시`.
- **종료/리셋 컨트롤을 만들지 말 것**(Q-D). `clearSample()`은 계정 이전에서만.
  결과는 알려진 사실: 샘플에서 지운 행은 그 브라우저에서 복구되지 않는다.
- R12 밴드(`.aoffer` 문법)를 **지나간 마감 다음**에. 리드 줄 없이 본문+CTA+닫기.
  세션당 1회, 닫기 가능, 익명 값 무변경. 숫자 위에 두지 말 것.

## 4b. 용어 (이번 세션 개정)

독자 표면에서 **「포트폴리오」를 쓰지 않는다** — 층 이름은 **보유 종목**(R8 nav slot).
`copy.ts` 개정 대상: `EMPTY_TITLE_KO` → 「보유 종목이 비어 있습니다」,
`SAMPLE_BANNER_KO` → 「샘플 보유 종목 — …」, 알림 레일 = `← ` + `PORTFOLIO_LABEL_KO`
(그 라벨도 **보유 종목**). 코드 경로·라우트·컴포넌트 이름은 그대로.

`Portfolio.module.css`의 **`@media (min-width:480px)`와 `@media (max-width:480px)`를 모두
삭제**하고 767 하나로 통합. 480 잔존 = 회귀 실패.

## 6. 회귀 체크리스트

1. 신규 한국어 0건 (`copy.ts` 무변경 — 재배치만).
2. 모든 D-day는 상류 값 — 브라우저 날짜 계산 0건.
3. 조회 ↔ 보유 종목 금액 동일(한 곱셈 자리, `lib/holding.ts`).
4. 지나간 행에 `--alert` **칩** 없음(금액만 alert, 체크 시 live).
5. 체크 = 라벨+색만. 금액·「추정」·집계 무변경. 캡션은 조건부 아님(점프 0px).
5b. 「놓친 돈 상세 →」는 **금액 줄 안**(라벨·기준 뒤), 체크된 행에는 **렌더되지 않는다**
   (해제 시 복귀). 컨트롤 줄 = 체크박스만. 금액 줄은 `min-height`로 컨트롤 높이를 상시
   보유(32px, ≤767 44px) — 링크가 사라져도 줄이 접히지 않는다. **체크 시 이동 0px**을
   측정으로 확인할 것. 이번 세션 개정.
6. 익명 쓰기 0건. 담지 않기가 브라우저 값을 지우지 않음.
7. 모달·오버레이·게이트 0건, `position:fixed` 0건.
8. `/portfolio`에 페이지 대제목 없음. `/portfolio/notifications`에 `h1` 하나.
9. 480px 미디어 쿼리 0건. ≤767 히트 영역 ≥44px.
10. 지나간 행: 링크는 금액 줄, 체크박스는 그 아래 줄, 캡션은 그 밑. 행 row-gap 4px.
11. 독자 표면에 「포트폴리오」 0건.
12. 계정 삭제 문장은 무장 전 0건.
13. 로그인 페이지 「실제 공시 4건」은 그대로(공시 건수 — 5행과 단위가 다름). 확인만.

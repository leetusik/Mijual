## 2. R2/R5 대비 변경 (서명 시 이 라운드가 해당 부분을 대체)

**Nav (R2 §Page shell 부분 대체)**
1. nav 유틸리티 슬롯의 **`[의견]` 칩 제거.** 의견 진입점은 푸터 링크 + 모바일 시트 행 두 곳뿐
   (R2 §6-4 「크롬 레벨, 떠 있는 버튼 금지」는 그대로 — 오히려 강화).
2. **「관제 현황판」 nav 링크 제거** — 현황판은 랜딩이고 링 워드마크가 이미 그 목적지다 (한 목적지를 바에서
   두 번 말하지 않는다). 남는 목적지는 **AI 질문 · 보유 종목** 두 개, 이 순서. 랜딩에서는 활성 링크 없음.
3. 목적지 슬롯 **보유 종목** 신설 → `/portfolio`. 로그아웃 = 샘플 포트폴리오, 로그인 = 본인
   포트폴리오. 랜딩의 「샘플로 열어보기 →」 링크와 그 아래 빈 밴드를 **대체**한다 (P7이 뺀 내 종목 조회
   슬롯 자리를 새 목적지가 아니라 이미 있는 표면으로 채운 것 — 기능 추가 아님).
4. 라벨은 두 상태 동일, nav에 「샘플」 배지 없음. **R5-4의 「샘플」 칩 + 「샘플 종료」 버튼 폐기** —
   로그아웃 상태의 `/portfolio`가 곧 샘플 포트폴리오다. 샘플임을 말하는 자리는 그 표면 하나(SampleBanner)이고
   크롬은 샘플에 대해 아무 말도 하지 않는다. 계정 슬롯 상태는 익명·로그인 **두 가지**뿐.
5. 불변: 52px · 투명 바 + 1px rgba(255,255,255,.12) · 링 워드마크 h19 · 링크 13.5px, 활성 600 + 2px
   #fff 밑줄 · 호버(색 변화만) · 포커스(P7 분리) · 모션.

**AccountSlot (R5 §Chrome 개정 ⑤ 대체)**
6. **축약 이메일 폐기 → 전체 이메일** (mono 12). 프레임 max-width 280px, 넘치면 말줄임 + `title`에 전체.
7. **아이디콘 20px**을 이메일 앞에 (신규 컴포넌트, §4).
8. **하이라인 프레임** 1px `--border-strong` + `▾` — 「메뉴다」라는 어포던스. 조용한 텍스트 링크였던
   R5의 형태는 클릭 가능성을 말하지 못했다. 호버/열림 = 표면 이동 + 보더 밝힘 (색 반전 없음).
9. **메뉴 정렬 수정** — 프레임 우변 기준 `right:0`, 최소 폭 = 프레임 폭, 오프셋 8px. 이메일과 화면 끝
   사이에 어긋나 걸리던 문제 해소.
10. 메뉴 행 = **알림 설정 / 로그아웃** (내 포트폴리오 행 삭제, Q3). 로그아웃 즉시·다이얼로그 없음(R5-1) 유지.
11. 메뉴 표면 **불투명 `#0e1a15`** — 코스모스가 목적지 목록을 통과해 읽히는 문제 (P3.S7 위젯과 같은 처리).

**Footer (R2 §Page shell 대체)**
12. 산문 4종 제거: 포지셔닝 줄 · 프로비넌스 문장 · 게이트 비용 문장 · 면책 문장.
13. 남긴 것 = 워드마크 h17 · 「자료: 금융감독원 DART 전자공시」 · 「© 미주알」 · 의견 보내기 · AI 질문.
    새 문장 없음. 한 줄 배치 (좌: 정체성 + 출처 / 우: 액션 2개), 상단 하이라인 하나.
14. **서체 교체**: 남은 한국어는 Pretendard 12/13.5 — mono 11 fine print 폐기. mono는 숫자 전용이라는
    R1 규칙의 복원이고, 푸터에는 숫자가 없다.
15. 390px = 3단 스택 (워드마크 → 출처·© → 액션 flex gap 24, 히트 ≥44px). 「AI 질문」이 혼자 줄바꿈되던
    문제 해소.

**NavMobile (R2 모바일 부분 대체)**
16. 시트가 본문을 밀던 인라인 동작 → **바에 매달린 오버레이 + 백드롭**(rgba(10,19,16,.72), 탭 = 닫힘).
    본문은 이동하지 않는다.
17. 바 버튼이 열림 상태에서 **×** 글리프로 전환. 라벨 「메뉴」는 유지하고 상태는 `aria-expanded` —
    「닫기」는 크롬 카피로 서명된 적이 없으므로 문구를 발명하지 않고 글리프로 처리.
18. 시트 행 구성: 목적지 2행 (AI 질문 · 보유 종목) → 구분선 → 계정 영역 → 구분선 → 의견 보내기. 로그인 시 계정 영역 첫 줄은
    **아이디콘 28px + 전체 이메일** (표기, 탭 대상 아님), 그 아래 알림 설정 / 로그아웃.
19. Esc·경로 변경 닫힘, 200ms 페이드, reduced-motion = 컷 — 전부 유지.

## 3. 의견 보내기 표면 (신규 — 미주알이 소유)

vocky는 임베드 위젯을 제공하지 않으므로 화면은 우리 것이다. 브라우저는 **미주알 자체 API**에만 말하고
키는 서버 `.env`에만 있다 (`VOCKY_API_KEY`; 어떤 기록·커밋·번들에도 등장하지 않는다).

- **여는 방식**: desktop 앵커 패널 380px (푸터 진입점 위로, 우변 정렬) · mobile 전폭 하단 시트 + 백드롭.
  둘 다 고정 떠 있는 버튼이 아니고 **우하단 모서리(AI 질문 런처)를 비운다** (R6 모서리 충돌 금지).
- **구성**: 헤더(제목 + × 28px) · 안내 한 줄 · 텍스트에어리어(104px, 모바일 120px) · fine print 두 문장 ·
  액션(닫기 quiet + 보내기 솔리드 `--live-solid`).
- **상태 6종**: 빈 입력(보내기 비활성 + 힌트 — 오류 아님) / 입력 중 / 보내는 중(입력 잠금, 라벨 교체,
  **스피너 없음**) / 접수됨(202 — 접수 번호 mono 표기) / 실패(**alert 색 금지** — inset + 다시 시도,
  입력 보존) / 닫힘.
- **연락처 없음**: 선택 입력조차 두지 않는다 (PII 0). 대신 표면이 스스로 「답장은 드리지 못합니다」를
  말한다 — 제품의 「거절하는 것을 소리 내어 말한다」 규칙.
- **신규 한국어 15개** (핸드오프 §2가 이번 라운드에 한해 허용): FeedbackStates 카드의 표가 정본.
  등재 대상 = `grounding/copy-inventory.md` + `frontend/components/chrome/copy.ts` (R8 인용과 함께).

## 4. 신규 컴포넌트 — Identicon

결정적 5×5 미러 격자, 사각 셀·사각 하이라인 프레임. 색은 해시가 고르는 **데이터 휴 4색**(`--r1`,
`--r2`, `--r3`, `--live`)만 — `--alert`(빨강 = 소멸·기한 예약)와 `--brand`(마크는 데이터 색을 갖지 않음)는
쓰지 않는다. 크기 20/28/40. 알고리즘·규칙은 `components/Identicon.prompt.md`, 계약은 build-prompt §5.

## 5. 세션 중 운영자 추가 지시 (핸드오프에 없던 것 — 위 항목에 반영됨)

1. **nav 목적지는 두 개** — 「AI 질문 · 보유 종목」. 관제 현황판은 랜딩이므로 링 워드마크 클릭이 그 자리 (§2-2).
2. **샘플 칩 · 샘플 종료 없음** — 보유 종목 페이지 하나로 (§2-4, §6-5).

이 두 건은 R8 서명 범위에 포함된다 — 적용 슬라이스는 build-prompt §1(목적지 표 + 샘플 슬롯 제거 항목)을
그대로 따르면 된다.

## 6. 이탈 · 미해결 (운영자 확인 필요)

1. **게이트 비용 문장과 면책 문장이 제품에서 사라진다.** 푸터가 게이트 비용 문장의 **마지막 배치**였고
   (R2.1 노트 4가 값 카드에서 제거), 면책도 다른 배치가 없다. 운영자 지시대로 제거했으나 ① 게이트 비용은
   「게이트가 포기한 금액」이라는 정직성 주장 자체이고 ② 면책은 금융 표면의 통상 문구다 — **랜딩 하단
   또는 「이용 안내」로 이전**을 제안한다. 결정은 P8의 다른 표면 라운드.
2. **푸터 mono → Pretendard.** R2의 「mono 11 bottom row」를 이탈. 근거: mono는 숫자 전용(R1)이고 남은
   줄에는 숫자가 없다. 운영자 지시 「Korean으로 읽히게」의 실행.
3. **× 글리프.** 「닫기」 문구를 만들지 않기 위한 처리. 문구를 원하면 카피 등재가 필요하다.
4. **메뉴·패널 불투명.** `--surface-card`(반투명)를 쓰지 않고 `#0e1a15` — P3.S7 개정 ①과 같은 판정.
   토큰이 아니라 리터럴이므로 이탈로 기록 (다음 토큰 개정 때 `--surface-opaque` 후보).
5. **R5-4 샘플 칩·샘플 종료 폐기.** 운영자 지시 — 「샘플 / 샘플 종료 없이 보유 종목 페이지만」. 로드 상태를
   크롬에서 표기하던 유일한 장치가 사라지므로, 샘플임을 말하는 책임은 전부 `/portfolio` 표면(SampleBanner)에
   있다. 「샘플 종료」로 되돌리던 경로도 없어진다 — 로그인 여부가 곧 상태.
6. **실패 상태에 alert 색 금지.** 빨강 의미 보존을 위해 오류를 빨강으로 칠하지 않는다 (R6 거절 문구와 동일).
7. **아이디콘 시드 출처** 미결(데이터 결정, Q5) — 시각 영향 없음.
8. 라운드 밖(운영자 확정): favicon 이월(D5) · 404 = Next 기본 유지 · 호버·포커스·모션 불변 ·
   `<title>`/메타 불변 · `/mcp` 범위 밖.

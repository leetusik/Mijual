## 나머지 findings

- **1** → Q-A. 부수 효과: 위젯의 `max-width` 가드는 768px 창에서도 440+48이 들어가므로 **회수**하고 짧은 창용 `max-height`만 남긴다.
- **2** → Q-B. **3** → Q-E. **4** → Q-F. **6** → Q-D. **7** → Q-C. **10** → 위 표.
- **5 도구 행의 접수번호 줄바꿈.** `word-break:break-all` **회수**. 행은 **한 줄**이고 넘치면 가로로 스크롤된다(`white-space:nowrap; overflow-x:auto; overscroll-behavior-x:contain`, 스크롤바 숨김) — 스트립의 「가로 스크롤 한 줄」과 같은 관례이며, 서버 문자열을 파싱하지 않고 R10 §0의 「숫자는 줄바꿈하지 않는다」를 지킨다.
- **8 빈 위젯의 가운데.** 범위가 이벤트면 인트로 아래에 **프리셋 한 줄**(스트립 재사용, 자유 입력 칩 없음 — 컴포저가 바로 아래에 있다). 범위가 전체 공시면 아래는 **비어 있고 그것이 상태다**: 빈 상태 카피를 만들지 않았다.
- **9 `/ask` 데스크톱의 리듬.** 두 열 = `minmax(0,760px) 340`, 묶음 `max-width:1124px` 가운데 정렬, 레일 `position:sticky; top:24px`. 1564px에서 프로즈가 열 하나를 가로지르지 않고 오른쪽 열이 페이지 높이만큼 비지 않는다. 바는 sticky이므로 짧은 스레드에서 **마지막 요소 바로 아래**에 서고 넘칠 때만 바닥에 붙는다.
- **11 hover 한 규칙.** 스트립 칩 = 테두리 soft→strong · 자유 입력 칩 = 거기에 ink-2→ink-1 · 인용 칩 = 테두리 rgba(.4)→불투명 `--live` · 솔리드 보내기 = **테두리만** `--live` · 헤더 아이콘·범위 × = ink-2→ink-1. 새 토큰 0건.
- **12 범위별 번호 차이.** 버그 아님 — 카드가 규칙을 있는 대로 그렸다(근거마다 번호 한 번). Q-B가 푸터를 그 규칙에 맞췄으므로 화면의 칩과 어긋날 수 없다.
- **13 disabled 보내기.** `opacity:.72` **회수** → 고스트 티어(배경 없음 · `--border-soft` · `--ink-3`). 감쇠된 솔리드는 누를 수 있어 보였다. 히트 36/44px 불변.
- **14 스레드 스크롤바.** 제품의 다른 패널과 같이 얇게(`scrollbar-width:thin`, thumb `--border-strong`, track 투명). 인용문 스크롤도 같은 규칙.
- **15 `get_contact` 연락처** — 이 라운드 것이 아니다(R6: 미정, 운영자 지정). **16 favicon 404** — chrome 스코프, R15.

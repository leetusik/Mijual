The evidence affordance behind every rendered fact: a compact `[근거]` chip that expands to the verbatim filing quote and links to the DART 원문 by `rcept_no`. One per field (an event card can carry six), never per card.

```jsx
<Citation rceptNo="20260724000546" quote="3) 신주인수권증서 상장예정기간 : 2026년 08월 19일~ 2026년 08월 25일" />
```

The quote is shown exactly as extracted — quotes range from one line to 600-character clauses; the panel scrolls past 180px. A field whose citation could not be located is never rendered at all, so this component never shows an empty state.

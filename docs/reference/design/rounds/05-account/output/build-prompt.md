# R5 Implementation Contract — 개인화 2층 (`P3.S6`)

For the Next.js build. Reference cards: `account/*.html`. **Token delta: none** —
`foundations/tokens.css` as landed in R2 (`.cosmos` scope on app pages).

## Naming + routes

- Layer name **내 포트폴리오** (R5-6 개정). Nav links: 내 종목 조회 · 관제 현황판 · 해설
  — 내 포트폴리오는 links가 아니라 계정 메뉴(스택 리스트) 첫 행. 내 포트폴리오 → 로그인
  게이트 (유일하게 게이트되는 표면); 그 외 전부
  익명 동작 유지.

## Auth (R5-1)

- 이메일+비밀번호 (개정). 로그인/계정 만들기는 한 패널 + 전환 링크; 비밀번호 8자
  이상(다른 규칙 없음); 재설정 = 이메일 링크(가입 여부 비노출). 저장 PII = 이메일 +
  비밀번호 해시.
- States: idle → 확인 중(버튼 텍스트 교체 + disabled, 스피너 없음) → 오류(본문 한 줄:
  불일치/중복 가입/8자 미만 — 로그인 오류는 필드 특정 없음) → 로그인됨. 로그아웃 즉시, 확인
  다이얼로그 없음, "로그아웃되었습니다" 1회 표시.
- PII 패널은 로그인 화면 상시 요소 (inset), 샘플 진입 링크는 하단 고정.

## Conversion (R5-2)

- 조회 결과 아래 offer 패널: 세션스토리지 플래그로 세션당 1회, 닫기 가능, 결과를
  가리지 않음. 상세 D-day 아래 한 줄 링크 (로그인 시 "내 포트폴리오에 담기 →"로 교체).
- nav 로그인 변경 금지. 게이트 화면·강제 모달 금지.

## Portfolio

- 입력은 R4 서명 프리미티브 재사용: mono 우측정렬, `inputMode="numeric"`, 콤마 그룹,
  프리셋 칩 100/500/1,000주. 저장 위치 캡션만 교체: "계정에 저장 · 마감 알림의 기준".
- 행: 종목 / 보유량(인라인 편집: input — 확정은 우측 액션 열이 수정·삭제 → 저장·취소로 교체, 가로 배치) / 진행 중인 권리 요약(RightsChip +
  governing label + `D-n · date`) / 수정·삭제. 삭제 = 즉시 + 8초 되돌리기, 모달 없음.
- 빈 상태 + 세션 이월 제안 (R5-3): sessionStorage에 R4 보유량이 있으면 inset 행 표시,
  담기/담지 않기 — 자동 저장 절대 금지. 담지 않기 → 세션 값 유지.
- 익명/샘플 편집은 localStorage 저장 — 로그인 없이 재방문에도 유지. 로그인 시 계정
  이전 제안(자동 이전 금지). 페이지 본문에 「내 포트폴리오」 대제목 없음 — header
  nav가 유일한 위치 표시.

## D-day 목록 (내 포트폴리오 홈)

- 섹션 2개: 다가오는 마감(D-day 오름차순) · 지나간 마감(최근순). 앵커 날짜 명기
  ("기준 YYYY-MM-DD (KST)"), 모든 D-day는 상류 계산값 — 브라우저 계산 금지.
- Per-type governing anchor: ① 증서 매매 마감 · ② 전환청구 개시 · ③ 반대의사 통지 마감.
- 금액 = R4 계약 그대로: ① 확정발행가 있음 → 「추정」 금액; 확정 전 → 주수 +
  `발행가 확정 전` 칩 + 확정 예정일; ②/③ → 금액 절대 없음 (② 희석 컨텍스트, ③ 2단계
  의존 문장). 내 종목 조회와 수치 불일치 금지 (같은 contract 소스).
- 지나간 행: inset 칩 `기간 지남 · D+n` / `통지 마감 지남 · D+n` — alert 색 금지.
  ① 소멸 행은 500주 기준 「추정」 금액 + "놓친 돈 상세 →" 링크(조회 breakdown으로).
- **챙긴 돈 체크 (R5-8)**: 지나간 ① 소멸 행에 체크박스 "청약·매도로 챙겼습니다".
  체크 → 라벨 놓친 돈 → 챙긴 돈, 금액 동일(「추정」 유지), alert → live, 캡션
  "본인 표시 · 계정에 저장". 사용자 주장 표시 — 공시 데이터와 혼동 금지(집계·통계에
  미반영), 계정에 저장, 샘플/익명에서는 이 브라우저(localStorage)에. 익명 조회(R4)의 조건문 프레임 불변.

## 알림 (R5-5, R5-7)

- 설정: 수신 주소(변경) · 마감 임박 시점 칩 다중선택 (7일/3일/1일/당일; 기본 7일+1일) ·
  KakaoTalk 행 = 라벨 + 「예정」 칩, 인터랙티브 컨트롤 렌더 금지 · 로그아웃 · 계정 삭제
  (이메일 즉시 삭제).
- 메일: 라이트 표면 (토큰 밖 — Notify 카드의 하드코딩 값 참조). 제목
  "[미주알] {종목} — {마감명} D-{n} ({date})". 본문 = 사실 블록(마감 mono D-표기 ·
  기간 · 보유 N주 기준 주수 · 발행가 상태) + "미주알에서 보기 →" + 푸터(rcept_no 출처 +
  해지 안내). 확정발행가 전 금액 금지 — 메일에도 동일. 발송 앵커 KST.
- 알림 외 메일(마케팅·다이제스트) 금지.

## 샘플 포트폴리오 (R5-4)

- 구성 (고정): 계양전기 500주 · 대동기어 300주 · 한화솔루션 500주 · 세기상사 100주
  (rcept_no는 result.md 표) — 실제 corpus 이벤트를 그대로 로드, 수치는 서버 contract에서.
- 진입: 로그인 페이지 하단 + 랜딩 푸터. 원클릭, 가입 없음.
- 로드 상태: 2층 표면에 inset 배너("구성 예시" 문구) + nav 「샘플」 칩 + 샘플 종료
  (로그인 슬롯 대체 — 메뉴 자리). 가짜 이메일·알림 이력 렌더 금지; 샘플에서 알림 설정 숨김.
  편집 가능 + localStorage 저장(로그인 불요, 재방문 유지); 로그인 시 이전 제안 → conversion offer.
- 종료: 샘플·브라우저 저장분 삭제 후 로드 전 상태 복귀.

## Chrome (logged-in)

- Desktop: links 불변(R2 삼분할) · 로그인 링크 → 축약 이메일 메뉴(mono, 앞 4자 +
  … + 도메인 끝): 내 포트폴리오 / 알림 설정 / 로그아웃. 그 외 R2 서명 불변 (52px, underline, 의견 슬롯).
- Mobile 시트: 구분선 + 내 포트폴리오(이메일 병기) / 알림 설정 / 로그아웃 — 계정 메뉴 영역. Footer 불변.

## Mobile (≤480px)

`account/AccountMobile.html`: 단일 컬럼, 타깃 ≥44px, 아코디언 없음. 지나간 마감은
요약 행(칩 + 한 줄), 종목 추가는 하단 패널.

## Hard rules (restated)

「추정」 없는 추정치/사실에 붙은 태그 — 금지. 확정발행가 전 금액(메일 포함) — 금지.
②/③ 금액 — 금지. 브라우저/비KST D-day — 금지. 과거 ② 개시 = 종료 표기 — 금지.
익명 경로 차단 — 금지. 가짜 사용자 정체성(이메일·이력) — 금지.
동작하지 않는 컨트롤(카카오톡 스위치) — 금지.

## Agent capabilities (operator note → designed surface)

도구 호출은 숨기지 않고 **사실 행**(mono, 좌측 hairline)으로 표시 — 무엇을 읽었는지가
근거의 일부: `이벤트 검색 「대동기어」 → 1건 · ② 전환사채 · 20251016000315` /
`내 포트폴리오 읽기 → 샘플 포트폴리오 · 4종목 (구성 예시)` / `의견 저장 → 운영자
검토 대기열`. 의견은 폼 없이 자동 저장 + 확인 한 줄; 답장용 이메일은 선택 입력.
